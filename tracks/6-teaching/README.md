# Track 6: Teaching

Write a problem set, solutions, and a grading rubric for a course you teach.

## Before you start

- The course, the topic, and what students should be able to do afterwards.
- Optional: your lecture notes or an old problem set.

## Steps

1. Make a folder for the course and start `claude` in it. Put any notes or old problem sets in it.
2. In plan mode, describe the course, the topic, the number of questions, and the level. Approve the plan and have Claude write the problem set.
3. Have Claude write the solutions in a separate file.
4. Check the solutions: start a new session and ask Claude to solve the problem set without seeing the solutions, then compare the two. Every difference is either a mistake or an unclear question.
5. Have Claude write a grading rubric: points per question and what earns partial credit.

## Finished when

- The problem set, the solutions, and the rubric are in separate files.
- The two independent solutions agree, or you've fixed the questions where they didn't.
